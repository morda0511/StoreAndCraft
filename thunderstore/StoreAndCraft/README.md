# StoreAndCraft

Auto-store ground items into nearby chests, dump your inventory, and craft or build from those chests. Rename a chest with **Alt+E** or **Shift+E**.

Must be on the **server and every client**. Do not run with AzuAutoStore or AzuCraftyBoxes.

Valheim 1.0, BepInExPack 5.4.2350+, no crossplay.

**Keys:** `.` dump · Mouse2 store hovered item · Alt+E rename · Alt+P pause · Alt+O toggle chest crafting · Y+click search

Config: `BepInEx/config/StoreAndCraft.cfg` and `StoreAndCraft.rules.yml`

This package contains AI-generated code.
